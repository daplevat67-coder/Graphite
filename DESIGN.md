# Карандашный блокнот

Приоритет dark_concept.png, также изучена светлая версия. NativeCompose/Canvas: бумага, горы, кольца, ручные контуры. Фактура — кэшированный192pxbitmapshader.

CURL иROLL зеркально следуют направлению перехода. По умолчанию3500мс, точная настройка1000–5000мс. Приходящая страница неподвижна; обратная сторона листа пустая, с объёмом/тенью. До2живых страниц; progress читается вdraw/layer, некаждыйкадрcomposition. Отрыв конфигурации остаётся после успешного удаления.

SketchReveal раскрывает меню строками с карандашным краем при открытии/обновлении. Скрытые ещё недорисованные контролы не принимают ввод. LoadingSketch показывается только при настоящем ожидании. ReduceMotion/отключение анимаций обходят движение. Полный зависший main-thread не маскируется анимацией; операции хранения/парсинга/измерений идут внеUI.

10motiontests проверяют nativeCanvas-пиксели,3.5сек,ROLLобратное направление, отмену, refresh/reduce motion. FPS на физическом телефоне не измерялся.
