# GRAPHITE VPN 0.2.2-alpha1

Продолжение существующего нативного Kotlin/Compose-приложения.

- Сохранён ключ подписи V0.2. versionCode повышен с3 до5. Сборка проверяет сертификат и останавливается при отсутствующем/другом ключе.
- В нижней панели вместо отдельного пинга — Серверы. В карточке есть ICMP-проверка, запуск/остановка WireGuard и сведения с трафиком/рукопожатием/событиями.
- Настоящий ICMP: три пакета, задержка из ответов ping, потери только для состоявшейся проверки; отсутствие ответа не выдаётся за неисправность VPN. Проверка идёт через текущую сеть, первый peer профиля.
- Перелистывание с изгибом, обратной стороной листа и тенью. Приходящая страница неподвижна. Значения анимации читаются при отрисовке, фактура бумаги кэшируется. Измерение FPS на физическом телефоне требуется отдельно.
- Исправлены гонки lifecycle/устаревших команд VPN-сервиса. Добавлены безопасные коды ошибок для диагностики; тексты исключений/ключи не выводятся.
- Advanced сохраняет все поддерживаемые поля WireGuard, сырую конфигурацию, несколько peers, DNS/маршруты/MTU/приложения.

Совместимое обновление возможно для V0.2 с сохранённым сертификатом. Для старой V0.1 использовался другой, утраченный ключ; эта сборка не может изменить подпись уже установленного приложения.

Результаты текущих проверок см. VALIDATION.md. Другие протоколы, включая AmneziaWG, ещё не подключаются.

Проверено: assembleDebug/assembleDebugAndroidTest/lintDebug, 52 host/JVM tests и3 instrumentation tests на Android9 — обновление без удаления с сохранением профиля, настоящий WireGuard HTTP/handshake/reconnect и ICMP loopback. Android15 device-run заблокирован нестабильностью программного эмулятора до запуска приложения.
