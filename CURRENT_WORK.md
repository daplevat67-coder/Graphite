# GRAPHITE VPN 0.3.0-alpha1

Graphite Tunnel 1 — собственный экспериментальный формат аутентификации и кадров поверх TLS 1.3. Клиент Android 10+ импортирует профиль по ссылке graphite://. Сервер Python находится в graphite-server/server.py, инструкция по запуску и формат протокола — в graphite-server/README.md.

Поддерживаются TCP и системные UDP-запросы A/AAAA, которые преобразуются в DNS-over-TCP через туннель. Прочий UDP блокируется. Сервер проверяет ключ и по умолчанию ограничивает назначения публичными адресами.

На локальном стенде Xray, Java-мост и Python-сервер передали HTTP-ответ и системный DNS-запрос A. Проверены отказ при неверном ключе, несовпадающем имени сертификата и попытке обратиться к loopback при стандартной конфигурации. Стенд использовал Java на Linux. Включение Android VPN на устройстве для этой сборки пока не проверено.

APK собран. Все 142 теста и Android lint прошли. Сертификат подписи совпадает с 0.2.12.
